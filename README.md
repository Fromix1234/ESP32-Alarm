# ESP32 Smart Alarm — часы-будильник на ST7789

Интерактивный будильник на ESP32 DevKit + TFT ST7789 1.54" 240×320.
Портретная ориентация **ROT 2**, проверена калибровкой.

## Возможности

- NTP-часы: время, дата, день недели;
- до **8 будильников**: время, дни недели, метка, вкл/выкл;
- веб-панель с телефона/ПК: добавить, изменить, удалить, тест, snooze, stop;
- кнопки A/B и BOOT: список будильников, инфо, snooze, stop, тест, день/ночь;
- плавный «рассвет» и ночной режим через PWM подсветки;
- настройки и будильники хранятся в NVS (переживают перезагрузку);
- mDNS: `http://alarm.local`;
- звук на телефоне через веб-панель (если нет бузера).

## Железо

- ESP32 DevKit (30/38 pin), CH340 → актуальный COM-порт (`COM5`/`COM6`, зависит от USB-порта);
- TFT 1.54" 240×320 **ST7789** (SPI);
- 2 тактильные кнопки (опционально, но удобно);
- Wi-Fi **2.4 ГГц**.

## Распиновка

| TFT | ESP32 |
|---|---|
| VCC | 3V3 |
| GND | GND |
| CS | GPIO5 |
| DC (A0) | GPIO2 |
| RESET | GPIO4 |
| SDA (MOSI) | GPIO23 |
| SCL (SCK) | GPIO18 |
| BLK / LED | **GPIO32** (PWM) |
| MISO | не подключать |

| Кнопка | ESP32 |
|---|---|
| A | GPIO25 → GND |
| B | GPIO26 → GND |
| BOOT | встроенная |

> BLK раньше был на 3.3 В. Теперь его нужно переключить на **GPIO32** —
> иначе не будет регулировки яркости и рассвета.
>
> Подробная пошаговая инструкция — [`WIRING.md`](WIRING.md).

## Wi-Fi

Заполните `include/secrets.h`:

```cpp
#define WIFI_SSID "ваша_сеть"
#define WIFI_PASSWORD "ваш_пароль"
#define WIFI_TZ "MSK-3"
```

Файл в `.gitignore`, в чат пароль отправлять не нужно. Сеть — 2.4 ГГц.
Часовой пояс можно поменять в веб-панели.

## Сборка и прошивка

```powershell
$pio = "C:\Users\fRoMiXpc\.pio-venv\Scripts\pio.exe"
$proj = "C:\Users\fRoMiXpc\Projects\esp32-tft-hello"

& $pio run -d $proj -e esp32dev                 # сборка
& $pio run -d $proj -e esp32dev -t upload       # прошивка
& $pio device monitor -d $proj                  # Serial 115200
```

Перед загрузкой (авто-сброс на этой плате не работает):

1. Зажать **BOOT**.
2. Коротко нажать **EN**.
3. BOOT не отпускать → запустить Upload.
4. После `Hash of data verified` отпустить BOOT и нажать **EN**.

В `platformio.ini` стоит `--before=no_reset` и `huge_app.csv` под Wi-Fi + веб.

## Что на экране

1. Заставка `SMART ALARM`.
2. Большие часы, дата и день недели.
3. Карточка следующего будильника.
4. Внизу: Wi-Fi/IP, адрес веб-панели, подсказки кнопок.
5. При звонке: `WAKE UP`, время, метка, солнце, пульсация подсветки.
6. При snooze: обратный отсчёт на карточке.
7. Кнопка A: список всех будильников с прокруткой (A — вверх, B — вниз).

## Кнопки

| Действие | A (25) | B (26) | BOOT |
|---|---|---|---|
| Обычно, коротко | список будильников | синхронизация + инфо | инфо |
| Обычно, удержание | день/ночь | тест | тест |
| Список, коротко | предыдущий (вверх) | следующий (вниз) | назад |
| Список, удержание | предыдущий (вверх) | тест выбранного | назад |
| Звонок, коротко | +5 мин | стоп | +5 мин |
| Звонок, удержание | стоп | стоп | стоп |
| Snooze, коротко | +5 мин | стоп | +5 мин |

Список автоматически закрывается через 15 секунд без нажатий.

## Веб-панель

После подключения к Wi-Fi откройте:

- `http://<IP-с-экрана>`
- или `http://alarm.local`

Там: живые часы, список будильников, форма добавления, настройки
часового пояса/яркости/ночного режима, кнопки «Тест», «Остановить»,
«+5 минут», а также звук на телефоне.

## API (кратко)

- `GET /api/state` — состояние;
- `POST /api/alarm` — добавить/изменить;
- `POST /api/delete` — удалить;
- `POST /api/action` — `test`, `snooze`, `stop`;
- `POST /api/settings` — `tz`, `brightness`, `autoNight`.

## Если что-то не так

| Симптом | Что проверить |
|---|---|
| Чёрный экран | BLK на GPIO32, VCC 3.3 В, GND |
| Белый экран | CS/DC/RST, контакты, SPI |
| Нет регулировки яркости | BLK всё ещё на 3.3 В |
| Нет Wi-Fi | 2.4 ГГц, SSID/пароль, перезагрузка |
| Время `--:--` | Wi-Fi/NTP, интернет на роутере |
| Кнопки не работают | GPIO25/26 → GND, замыкание при нажатии |
| Не прошивается | BOOT+EN, актуальный COM-порт, CH340 |
